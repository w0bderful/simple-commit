# SimpleCommit Web

Windows PC에서 실행하는 로컬 웹 애플리케이션입니다. 별도 Node.js/Python 설치 없이 .NET Framework 4.7.2 이상에서 실행합니다.

## 실행

`SimpleCommit.Web.exe`를 실행하면 기본 브라우저에서 http://127.0.0.1:17843 이 열립니다. 이미 실행 중이면 기존 웹 앱을 엽니다. 브라우저를 닫아도 트레이 서버는 계속 동작합니다. 완전히 종료하려면 트레이 아이콘을 우클릭해 **종료**를 선택하세요.

인터넷에는 공개되지 않으며 같은 PC에서만 접속할 수 있습니다. 사이트는 GitHub Pages 등 정적 호스팅에 올리는 형태가 아닙니다. PC가 꺼져 있거나 서버가 종료되어 있으면 자동 확인도 멈춥니다.

## 기능

- GitHub, GitGud, Codeberg, GitLab.com의 공개 저장소 지원
- 단일/일괄 등록, 링크 입력 시 브랜치 자동 조회, 수정 및 삭제
- 커밋 상대 시각, ZIP 최신 여부, 검색, 최근 커밋순 정렬, 드래그 순서 변경
- 전체 선택/취소와 선택 목록 기억, 선택 ZIP 다운로드
- 지정 폴더에 `저장소명-브랜치.zip` 저장; 검증 후 교체, 연결된 이전 ZIP 삭제, 최신 버전 건너뛰기
- 기존 ZIP 자동 탐색 및 행 메뉴에서 수동 연결
- 행 이름 링크/더블클릭/오른쪽 메뉴로 저장소 페이지 열기
- 확인 간격, 기본 폴더, Windows 자동 시작, 밝은/검은색 머터리얼 테마
- 무음 웹 알림, 확인할 때까지 유지 또는 표시 시간 설정. 브라우저를 다시 열면 서버 실행 중에 쌓인 미확인 알림을 표시
- **설정 → 저장소 목록 → 목록 내보내기 / 목록 가져오기**

목록 내보내기는 JSON 파일에 모든 저장소의 URL, 브랜치, 다운로드 폴더, 선택 상태, 커밋 및 ZIP 정보를 저장합니다. 가져오기는 기존 목록에 합치며 같은 저장소·브랜치는 건너뜁니다. 기존 데스크톱 앱의 `repositories.json`도 가져올 수 있습니다. 잘못된 항목이 있으면 전체 가져오기를 취소합니다.

## 데이터

`%LOCALAPPDATA%\SimpleCommitWeb\settings.json`: 웹 앱 설정

`%LOCALAPPDATA%\SimpleCommitWeb\repositories.json`: 저장소 목록

이전 버전 설정과 목록은 자동으로 가져오지 않습니다. 필요한 목록은 설정에서 JSON 파일로 직접 가져오세요. 웹 앱 자동 시작은 기본적으로 꺼져 있으며 설정에서 켤 수 있습니다. 이전 앱과 웹 앱이 동시에 같은 ZIP을 갱신하지 않도록 한쪽만 실행하세요.

설정 저장 시 `.bak`을 남깁니다. 파일을 읽지 못하면 빈 목록으로 덮어쓰지 않고 실행 오류를 표시합니다.

## 빌드

저장소 루트의 `SimpleCommit.cs`를 재사용합니다. 이 디렉터리에서 `powershell -File build.ps1`을 실행합니다. HTML/CSS/JavaScript와 아이콘은 EXE에 포함되어 실행 시 별도 폴더가 필요하지 않습니다.

개발용: `SimpleCommit.Web.exe --tray --port 17844 --data C:\원하는\테스트폴더`

로컬 API는 루프백 IP에만 바인딩하며 Host/Origin 검사와 실행별 요청 토큰을 사용합니다. 외부 웹사이트의 직접적인 파일 작업 요청을 받지 않습니다.
