커밋 알리미
지원: GitHub · GitGud · Codeberg · GitLab.com 공개 저장소

등록
- '+ 추가': 링크 입력 시 브랜치 자동 탐색. 기본 브랜치 또는 원하는 브랜치를 선택합니다.
- '여러 개 추가': 링크를 한 줄씩 붙여 넣어 기본 브랜치로 일괄 등록합니다.
- 중복 링크는 제외하며 잘못된 링크는 행 번호로 안내합니다.
- '기본 다운로드 폴더': 새 저장소에 사용할 폴더를 지정합니다. 기존 저장소의 폴더는 유지됩니다.
- '수정': 개별 저장소의 주소, 브랜치, 다운로드 폴더를 변경합니다.

항상 자동 확인
- 실행 시 모든 저장소를 즉시 확인하며, 이후 지정한 간격으로 계속 확인합니다.
- 설정 탭의 '자동 확인 간격'에서 간격을 변경합니다. 기본 180분, 범위 1~10080분입니다.
- 간격은 자동 저장됩니다. 변경 시 현재 시각부터 새 간격으로 다음 확인을 예약합니다.
- 별도 시작/중지 버튼은 없습니다. 완전히 종료하려면 트레이 메뉴의 종료를 사용하세요.
- PC/프로그램이 꺼져 있거나 절전 중에는 확인하지 않습니다.
- 절전 복귀 후 예정 시각이 지났으면 다음 타이머에서 확인합니다.
- '전체 지금 확인'으로 언제든 즉시 확인할 수 있습니다.

목록
- 저장소 / 브랜치 / 커밋 경과 시간 / 최신 커밋 / 내 ZIP / 확인 상태
- '7분 전', '2시간 5분 전' 등은 서버의 committer date 기준이며 15초마다 갱신됩니다.
- 행 선택 시 아래에 정확한 커밋 시각, 마지막 확인 시각, 연결한 ZIP 경로가 표시됩니다.
- 더블클릭: 저장소 웹페이지를 기본 브라우저로 엽니다.
- 오른쪽 클릭 → 삭제: 목록에서만 제거합니다. ZIP 파일은 삭제하지 않습니다.

선택 다운로드
- 체크한 저장소만 각 저장소의 폴더에 순서대로 다운로드합니다.
- 전체 선택 / 전체 취소 버튼이 있으며 체크 목록은 재실행 후에도 유지됩니다.
- 일부 실패해도 나머지는 진행하고 최종 저장/건너뜀/실패 개수를 표시합니다.
- 프로그램에 기록된 최신 ZIP이 정상적으로 있으면 중복 다운로드를 건너뜁니다.
- 자동 압축 해제나 기존 파일 덮어쓰기는 하지 않습니다.

기존 ZIP 자동 연결
- 등록, 실행, 정기 확인, 지금 확인 시 자동으로 탐색합니다.
- 탐색 위치: 저장소별 폴더, 기본 다운로드 폴더, 사용자 Downloads 폴더 바로 아래의 ZIP.
- 프로그램에서 받은 파일명 및 사이트 기본 ZIP의 최상위 폴더명을 확인합니다.
- 저장소명, 브랜치명, 커밋 ID를 식별할 수 있는 파일을 자동으로 연결합니다.
- ZIP 끝의 git archive 커밋 정보도 읽습니다.
- 같은 이름의 저장소 때문에 연결 대상이 모호하거나 ZIP이 손상되었으면 자동 연결하지 않습니다.
- 식별할 수 없는 이름이나 다른 위치의 파일은 '기존 ZIP 연결'로 직접 지정할 수 있습니다.
- 최신 ZIP: 프로그램에 기록된 다운로드와 마지막 서버 확인 커밋이 일치합니다.
- 최신 추정 · 연결 ZIP: 기존 파일의 커밋 정보를 기준으로 일치합니다. 내용 전체를 비교한 것은 아닙니다.
- ZIP 업데이트 필요: 다운로드한 커밋과 서버 커밋이 다릅니다.
- 기존 ZIP · 버전 미확인: 파일은 연결했으나 커밋 버전 정보를 알 수 없습니다.
- 자동 연결한 ZIP도 식별된 커밋 ID가 서버의 최신 커밋과 일치하면 다운로드를 건너뜁니다. 버전을 식별하지 못한 파일이나 손상된 ZIP은 다시 다운로드합니다.
- 최신 판정은 마지막 성공한 서버 확인 기준입니다.

윈도우 / 트레이
- 윈도우 로그인 시 창을 띄우지 않고 트레이에서 시작합니다. 체크 해제로 자동 시작 등록을 끕니다.
- 창 X 버튼은 트레이로 숨깁니다. 아이콘 더블클릭으로 창을 엽니다.
- 트레이 우클릭 → 종료로 완전히 종료합니다.
- EXE를 옮겼다면 새 위치에서 한 번 실행하세요.

설정: %LOCALAPPDATA%\SimpleCommit\settings.json
Windows 10/11, .NET Framework 4.7.2 이상

목록 정렬
- '최근 커밋순' 버튼: 최신 커밋이 위로 오며, 새 조회 결과에도 정렬이 적용됩니다. 커밋 시각 미확인 항목은 아래에 표시됩니다.
- 버튼을 다시 누르면 현재 순서를 유지하는 수동 정렬로 바뀝니다.
- 행을 마우스로 잡아 원하는 위치에 놓으면 표시된 삽입 위치로 이동합니다.
- 드래그하면 최근 커밋 자동 정렬을 해제하고 수동 순서를 저장합니다.
- 목록 순서와 체크 상태는 다음 실행에도 유지됩니다.
- 확인 또는 다운로드가 진행 중일 때에는 정렬 작업을 잠시 비활성화합니다.

설정 탭과 자체 알림
- 설정 탭: 자동 확인 간격, 윈도우 자동 시작, 기본 다운로드 폴더, 알림 표시 시간, 기존 ZIP 수동 연결.
- Windows 알림 대신 프로그램 자체 알림을 오른쪽 아래에 표시합니다.
- 기본적으로 확인하거나 ×로 닫을 때까지 알림을 계속 표시합니다.
- 설정에서 "확인할 때까지 알림 유지"를 끄면 1~120초 표시 시간을 사용할 수 있습니다.
- 알림 미리보기 버튼으로 표시를 확인할 수 있습니다.
- 알림 클릭은 저장소 목록을 열고, × 버튼은 알림만 닫습니다.
- 알림은 포커스를 가져오지 않으며 작업 표시줄 위쪽에 표시됩니다.

설정 및 목록 저장 위치: %LOCALAPPDATA%\SimpleCommit
- settings.json: 프로그램 설정
- repositories.json: 저장소 목록, 선택 상태, ZIP 및 커밋 정보
- 기존 통합 설정은 자동으로 분리되며 .bak 백업을 보관합니다.
